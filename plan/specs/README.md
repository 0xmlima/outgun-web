# Specs de engenharia reversa

Uma spec por tema (`fisica-movimento.md`, `bandeiras-captura.md`, ...), criada pela skill `outgun-re-spec` antes de implementar cards de port (v1; na v2 a skill está desativada em `.claude/skills-disabled/` e as specs descrevem o comportamento herdado do original). Cada afirmação deve citar `arquivo:linha` do código original.
